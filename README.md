# Проект по автоматизации тестирования web-приложений.

Проект 4-го спринта. Задание описано в `Task.md`.

## Реализованные тесты
**Основное задание:**
* `NewOrderTestCase`
  * Проверяет возможность оформления нового заказа
  * Проверяет возможность заказа различных цветов самокатов и различную продолжительность аренды
* `VerifyOrderButtonHeaderTestCase`
  * Проверяет переход на страницу оформления заказа через кнопку в шапке (далее тест был бы аналогичен `NewOrderTestCase`)
* `VerifyOrderButtonMiddleTestCase`
  * Проверяет переход на страницу оформления заказа через кнопку на домашней странице (далее тест был бы аналогичен `NewOrderTestCase`)
* `VerifyFaqAnswersTestCase`
  * Проверяет ответы в разделе FAQ

**Дополнительное задание:**
* `VerifyYandexLogoTestCase`
  * Проверяет, что если нажать на логотип Яндекса, в новом окне откроется главная страница Яндекса
* `VerifyScooterLogoTestCase`
  * Проверяет, что если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката»

Вне задания:
* `VerifySelectEachStationTestCase`
  * Проверяет возможность выбора каждой станции в форме заказа
* `VerifyCorrectTrackTestCase`
  * Проверяет поиск существующего заказа
  * Недоделано (нет проверки на корректность выводимых данных)

## Управление запускаемым браузером

Для смены запускаемого браузера необходимо в файле `Config` изменить значение переменной `BROWSER` на `"firefox"`. В этом же файле задан размер задержек по умолчанию.

Все остальные параметры браузера можно задать/изменить в файле `DriverFactory`.
